================================================
  ESG报告数据智能提取与分析系统 - 使用说明
================================================

【唯一系统入口：Streamlit】

本项目当前只保留 Streamlit 作为评审和演示系统。
旧版单文件网页交付已废弃，不再作为提交或演示入口。

【方式一：Windows 一键启动】

  1. 双击 setup.bat
     → 安装 Python 依赖，并提示配置 DeepSeek API Key

  2. 双击 start.bat
     → 启动 Streamlit 系统

  3. 浏览器访问
     → http://localhost:8501

【方式二：命令行启动】

  pip install -r requirements.txt
  python run.py app

  或者：

  streamlit run streamlit_app.py

【AI 智能助手配置】

  如需使用“AI智能助手”页面，请在项目根目录创建 .env 文件：

  DEEPSEEK_API_KEY=你的DeepSeek_API_Key

  API Key 获取地址：
  https://platform.deepseek.com/

【系统页面】

  Streamlit 系统包含：
  - 首页概览
  - 数据质量
  - 公司详情
  - 指标对比
  - ESG分析
  - 趋势分析
  - AI智能助手
  - 数据管理

【数据处理流程】

  python run.py download     下载ESG报告PDF
  python run.py preprocess   PDF正文、表格和OCR预处理
  python run.py extract      DeepSeek结构化抽取ESG指标
  python run.py validate     校验抽取结果质量
  python run.py db-import    导入SQLite数据库
  python run.py analyze      生成ESG评分和行业分析
  python run.py app          启动Streamlit系统
