================================================
  ESG数据智能提取与分析系统 - 使用说明
================================================

【方式一：自包含HTML（推荐用于赛题提交）】

  直接双击打开 "ESG分析系统_自包含版.html"
  → 浏览器即可使用，零安装、无需API Key、无需联网*
  → 包含6大功能页面：数据概览、ESG排名、公司查询、指标对比、行业分析、智能检索
  → *Plotly图表需首次CDN加载，之后可离线缓存

【方式二：完整AI版（Streamlit应用）】

  1. 双击 setup.bat → 安装依赖 + 配置API Key
  2. 双击 start.bat → 启动系统，浏览器打开 http://localhost:8501
  3. 点击 "🤖 AI智能助手" 进行自然语言查询

  需要：Python 3.10+、联网（调用DeepSeek API）

【提交材料清单】
  赛题提交时建议包含：
  ✓ ESG分析系统_自包含版.html （核心成果，双击即可体验）
  ✓ src/ 源代码目录
  ✓ requirements.txt
  ✓ 使用说明.txt

【API Key 获取】
  访问 https://platform.deepseek.com/ 注册 → API Keys → 创建新Key
